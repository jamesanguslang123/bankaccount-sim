# Python Bank Account Simulator

A beginner Python project demonstrating object-oriented programming through a simple bank account simulation.

## Features
- Create a bank account with an owner's name and initial balance.
- Display account information and current balance.
- Deposit money into an account.
- Withdraw money from an account.
- Prevent withdrawals that exceed the available balance.
- Interactive menu allowing users to manage their account.

## Concepts Practised
- Object-oriented programming (OOP)
- Classes and objects
- Constructors (`__init__`)
- Attributes and methods
- User input
- Conditional statements
- While loops
- Modifying object attributes
- Basic input validation

## Technologies
- Python 3

## How to Run
1. Clone or download this repository.
2. Open the project in VS Code.
3. Run the following command:

```bash
python bank_account_simulator.py
```

## Purpose
This project was created to develop my understanding of Python object-oriented programming and learn how classes and objects can be used to build practical applications.
